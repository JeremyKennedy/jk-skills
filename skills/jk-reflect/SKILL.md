# Reflect

Pause. Challenge assumptions. Evaluate whether the current direction is right.

## When to Use

- You've lost sight of the original goal
- A decision feels wrong but you can't articulate why
- The user asks you to step back or reconsider
- You're about to commit to a direction and want a sanity check

## Light Reflection (default)

Answer these questions concisely:

1. **Goal**: What are we trying to accomplish? Has it drifted?
2. **Drift**: How did we get here? Which decisions were deliberate, which were accidental?
3. **Assumptions**: What unverified assumptions are we making?
4. **Alternatives**: What approaches did we dismiss? Should any be reconsidered?
5. **Risks**: What could go wrong with the current direction?
6. **Recommendation**: One clear action — stay the course, adjust, or rethink — with brief reasoning.

Be honest, not diplomatic. "We're on track" is valid when true.

## Deep Reflection

For consequential decisions (architecture, scope, high-stakes changes), you may optionally dispatch a fresh agent with no investment in the current approach. Prompt it to challenge goals, approach, assumptions, and overlooked alternatives, then return an assessment and recommendation. Deep reflection is a tool, not a requirement — use it when your own biases might cloud judgment.

## After Reflecting

Present findings concisely with a clear recommendation, then act on it. Don't reflect for the sake of it; don't use reflection to procrastinate.
